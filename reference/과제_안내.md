# Lv.2 과제 안내

전체 모듈 과제 요구사항은 [과제 발제문서](과제_발제.md)를 따릅니다. 미니 퀴즈·실습 산출물·모듈 과제는 서로 다른 평가 축이며 최종 반영 비율, 기한과 재제출 정책은 운영 공지에 따릅니다.

## 모듈 1

오늘은 [과제 1 발제문서](모듈1_임베디드제어기초/과제1_발제_SSH_라즈베리파이_OpenCR.md)의 환경 구성과 문제 1만 제출합니다. 라즈베리파이 Ubuntu Server 22.04에 SSH로 접속하고 업로드·시리얼 수신·로그 저장을 모두 라즈베리파이에서 수행해야 합니다.

[OpenCR·다이나믹셀 통합 4문제](모듈1_임베디드제어기초/과제_발제_OpenCR_다이나믹셀_4문제.md)가 기존 모듈 1 과제를 대체합니다. 각 25점, 총 100점으로 평가하며 기존 성취도 엑셀의 1~5점 기준으로 자동 환산하지 않습니다.

1. 목표 입력과 움직임 확인
2. 측정값·오차·피드백 해석
3. Kp 두 가지 설정 비교
4. 제공 통신 기록과 제어 흐름 해석

결과 설명은 `lv2_module1/report.md`에 문제 순서대로 작성합니다. 문제 1~4를 모두 작성해도 표·구조도를 포함해 A4 약 2쪽 분량을 권장하며, 파일 형식은 Markdown을 유지합니다. 모델·ID·Kp·목표각·속도 상한·예제 이름을 기록하고 실행 A·B 증거는 `lv2_module1/results/`에 저장합니다. 제공 코드를 수정했다면 변경 파일도 같은 모듈 폴더에 포함합니다.

가상 데이터와 제공 로그는 실측 결과와 구분해 표시합니다. 미실행 하드웨어 과정을 완료로 표시하지 않습니다. 실패한 결과도 설정·측정·해석이 일치하도록 기록합니다.

## 모듈 2~10

전체 발제문서의 해당 모듈 제출 형식과 성취도별 기준을 따릅니다. 모듈 1의 축소 기준을 다른 모듈에 적용하지 않습니다.


## 제출 저장소와 폴더 구조

SpartaPA 조직에 수강생별 **`physicalai-lv2-이름`** 저장소를 하나 만드세요. 예: `SpartaPA/physicalai-lv2-홍길동`. 조직에 생성할 권한이 없으면 담당 튜터에게 권한을 요청하세요. 개인 계정의 저장소로 대신 제출하지 않습니다.

모든 모듈 과제를 같은 저장소에 누적합니다. 각 모듈을 시작할 때 `lv2_module1/`부터 `lv2_module10/`까지 해당 폴더를 추가하세요. 처음부터 비어 있는 폴더 10개를 만들 필요는 없습니다.

```text
SpartaPA/physicalai-lv2-이름
├── README.md
├── lv2_module1/
│   ├── README.md
│   ├── report.md
│   └── results/
├── lv2_module2/
│   ├── README.md
│   ├── report.md
│   └── ...
├── ...
└── lv2_module10/
    ├── README.md
    ├── report.md
    └── ...
```

- 루트 `README.md`: 수강생 이름과 모듈별 제출 폴더 링크.
- 모듈별 `README.md`: 장비·환경, 실행 방법과 결과 파일 위치.
- 모듈별 **`report.md`**: `## 문제 1`, `## 문제 2`처럼 문제 순서대로 설정·증거·검증·해석 작성.
- 결과 파일은 해당 모듈의 `results/` 또는 발제문서에서 지정한 하위 폴더에 저장하고 `report.md`에서 상대 경로로 연결합니다.
- 압축파일이나 별도 답안 파일로 제출하지 않습니다. 코드·로그·설정 등 요구된 산출물은 모듈 폴더에 함께 커밋합니다.
- 팀 과제도 각 수강생의 같은 저장소 내 해당 모듈 폴더에 결과와 본인의 기여를 남깁니다. 공통 작업 저장소가 있다면 링크와 기준 커밋을 기록합니다.

## 제출 완료 기준

모듈의 모든 문제가 완료되면 Lv.1과 같은 방식으로 최종 커밋에 **`lv2-module{번호}-submit`** 태그를 붙여 원격 저장소에 올립니다. 예: `lv2-module1-submit`. 저장소 URL과 해당 태그 URL을 지정된 제출 경로에 등록하세요. 기한과 재제출 정책은 운영 공지에 따릅니다.

오늘은 문제 1의 중간 제출이므로 `lv2_module1/report.md`의 `## 문제 1`과 관련 기록을 커밋·푸시하고 해당 커밋 또는 문서 URL을 제출합니다. 모듈 1 전체 완료 태그는 문제 1~4를 모두 마친 뒤 붙입니다.
