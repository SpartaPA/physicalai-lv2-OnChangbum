## 오늘의 제출 범위

모듈 1의 문제 1을 수행합니다. 라즈베리파이 Ubuntu Server 22.04에 SSH로 접속하여 환경을 구성하고, OpenCR 펌웨어 업로드와 시리얼 기록 수집을 모두 라즈베리파이에서 수행해야 합니다. PC는 SSH 접속용으로만 사용합니다.

모듈 1은 개정된 4문제·각 25점 기준을 우선합니다. 나머지 모듈은 전체 발제문서의 기준을 따릅니다. 제출일과 제출 경로는 운영 공지에 따릅니다.

## 제출 방식

SpartaPA 조직의 `physicalai-lv2-이름` 저장소 하나에 모든 모듈 과제를 누적합니다. 각 모듈은 `lv2_module{번호}/` 폴더를 사용하고, 결과 설명은 해당 폴더의 **`report.md`**에 작성합니다. 오늘은 `lv2_module1/report.md`의 문제 1을 제출하며 나머지 문제는 같은 문서에 추가합니다.

폴더 구조와 최종 제출 태그는 [과제 안내](과제_안내.md#제출-저장소와-폴더-구조)를 확인하세요.
