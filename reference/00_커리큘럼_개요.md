### Lv.2 추가 원칙 (난이도 상승에 대응하는 5가지 장치)

Lv.2부터 수식과 전문 용어가 크게 늘어나는 만큼, 수강생이 **설명의 연결고리와 학습 기준**을 잡을 수 있도록 모든 강의에 아래 다섯 장치를 넣습니다.

1. **강의별 필수 이해 기준** — 학습 목표 바로 아래에 `> **오늘의 필수 이해 기준**` 블록. 모든 수강생이 반드시 도달해야 하는 **필수 3항목**과, 지금 막혀도 되는 **심화 항목**을 구분해 먼저 안내합니다.
2. **현상 → 직관 → 수식 → 해석 → 적용의 흐름** — 주요 수식은 수식부터 제시하지 않습니다. `**현상**`(실제 로봇에서 무엇이 일어나는가) → `**직관**`(왜 그런가) → `**수식**`(어떤 변수와 관계식인가) 순서로 이어 쓰고, 해석·적용은 다음 항목의 표가 담당합니다.
3. **수식 읽기 표** — 핵심 수식마다 `**수식 읽기** — 〈수식〉` 다음에 5행 표를 둡니다: **이 수식이 답하는 질문 / 기호와 단위 / 각 요소의 물리적 의미 / 실습·코드와의 연결 / 이해 수준(필수·심화)**. 계산만이 아니라 **해석**할 수 있게 하는 것이 목적입니다.
4. **용어 사전** — 강의 하단(정리 다음, 질문사항 앞)에 `## 용어 사전` 표를 둡니다: **용어 / 쉬운 표현 / 왜 필요한가·어디에 쓰는가 / 자주 혼동하는 개념**. 신규 전문 용어는 본문 최초 등장 시에도 한 번 풀어 씁니다.
5. **인터랙티브 자료** — 변수의 변화가 그래프·물리 현상을 어떻게 바꾸는지 직접 확인해야 하는 주제는 `Lv2/인터랙티브/` 폴더의 단일 HTML 파일로 제공하고, 해당 강의 상단에서 링크합니다(설치·인터넷 불필요). 목록은 `Lv2/인터랙티브/README.md` 참고.

> 본 폴더의 각 `.md` 파일은 Notion에 이관하여 강의 페이지로 사용합니다. 이미지는 `images/` 폴더의 PNG를 Notion에 직접 업로드합니다.
